# Python CI Job

The `test-python` job in `.github/workflows/ci.yml` runs the Python test suite for `packages/adapter-python-process` against a 3.12 × 3.13 matrix. Each matrix cell checks out the repo, installs `astral-sh/setup-uv` (pinned to SHA `08807647e7069bb48b6ef5acd8ec9567f424441b`, tagged v8.1.0 — a SHA pin ensures deterministic builds regardless of floating tag mutations), and runs `uv run --frozen pytest` in `packages/adapter-python-process/`. The `--frozen` flag requires `uv.lock` to be committed alongside `pyproject.toml`; the job will fail fast if the lock file is missing or stale. `actions/setup-python` is intentionally absent: `uv` fetches and manages its own Python interpreter for each matrix version. `fail-fast: false` is set so a 3.12 failure does not cancel the 3.13 run, allowing both version results to be visible in a single CI run.
